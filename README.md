# CareOS 🏥
The AI-powered command center for family healthcare.

## 🚀 Features
- Vision AI: Snap photos of prescriptions to simplify medical jargon.
- Multilingual: Instantly translates reports to Hindi, Tamil, and English.
- Abnormal Highlighting: Flags high values in red.
- Family Log: Real-time medication tracking to prevent double-dosing.

## 🛠️ Tech Stack
- Frontend: HTML, Tailwind CSS
- AI Engine: OpenAI GPT-4 Vision (planned integration)
