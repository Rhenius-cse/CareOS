# CareOS 🏥
The AI-powered command center for family healthcare.

## 🚀 The Problem
Medical reports are full of jargon. Language barriers prevent understanding. Family caregivers lack a unified system, leading to accidental double-dosing.

## 💡 Our Solution
CareOS uses Vision AI to snap photos of prescriptions, simplifying them into plain Hindi/Tamil/English. It highlights abnormal values and features a real-time "Family Log" so everyone knows when Mom or Dad took their meds.

## 🛠️ Tech Stack
- Frontend: HTML, Tailwind CSS
- AI Engine: OpenAI GPT-4 Vision (planned integration)
- Database: Firebase (planned integration)
